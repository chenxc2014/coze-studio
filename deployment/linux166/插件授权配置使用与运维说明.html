插件授权配置使用与运维说明

部署配置、磁盘规划与日常维护操作。容量和验收状态为原文记录的历史快照。

打开平台 下载 Markdown

更新日期：2026-11-11。平台入口：https://ai.yaoxiaoyi.com/agent/。

使用入口

使用平台管理员账号登录，进入“配置管理 → 插件授权配置”，或直接打开 插件授权配置。普通账号无法读取、修改或测试这些授权。

当前支持天眼查和高德地图。凭据由平台内使用相应插件的智能体及其它插件执行场景共用，供应商调用额度合并消耗。保存凭据不自动为智能体增加工具，也不代表供应商已经开通全部接口。

录入和测试

  1. 在天眼查开放平台取得 API Token，并开通需要的接口权限；高德使用 Web 服务 Key。
  2. 在对应卡片输入新凭据，点击“保存授权”。保存后输入框清空，只显示“已配置”状态，不回显密钥或密钥片段。
  3. 点击“测试已保存配置”，系统实际请求供应商，分别测试天眼查经营异常查询和高德周边搜索。测试可能计入供应商调用额度，按返回的业务状态判断是否通过。
  4. 输入框留空会保留原值。输入了新值但尚未保存时，测试按钮不可用，避免误测旧配置。
  5. 如需停用这份凭据，点击“清除授权”并确认。该操作影响所有共用此插件授权的调用，且不会重新回退到旧配置文件里的密钥。

保存和清除对后续调用即时生效，不需要重启后端。已经开始的调用使用其取得的凭据快照。

“已配置”仅表示后台保存了凭据；“测试通过”才表示本次测试的接口成功。测试通过仍不表示同供应商的其它业务接口均已授权。测试错误不会将供应商原始响应中的密钥、请求头或带密钥 URL 返回页面。

凭据存储与生效顺序

  • 数据库使用已有 kv_entries，命名空间为 plugin_service_credentials，键为 amap、tianyancha，无需新增数据库表。
  • 密钥使用 AES-256-GCM 加密，包含随机 nonce 和供应商关联校验。数据库记录只保存密文、最后修改人和修改时间。
  • 加密主密钥由服务器独立持久保存，环境变量 PLUGIN_CREDENTIAL_KEY_FILE 指向容器中的只读挂载文件。没有内置默认主密钥。
  • 166 主密钥：/home/coze/secrets/plugin-credential.key，32 字节，权限 0600；容器路径：/run/secrets/coze-plugin-credentials.key。
  • 后台尚未写入该供应商配置时，兼容原内置插件 YAML 中的服务授权。后台保存后优先使用数据库配置；显式清除后禁止回退旧文件值。
  • 每次插件调用读取持久配置，并复制当前请求的认证对象，避免把密钥写回共用插件目录或返回普通用户的插件详情。

首次部署需由运维在仓库外生成并持久保存随机 32 字节主密钥，再设置只读挂载与环境变量。166 已完成该步骤。原主密钥丢失时应恢复匹配的备份，不能通过重新生成另一份随机密钥解密旧记录。

真实供应商凭据和主密钥不得写入 Git、HTML、Markdown 或浏览器存储。管理接口省略请求和响应体的访问日志；插件诊断请求中的认证请求头和查询参数被脱敏，网络错误及供应商返回中已知的凭据值也会被清理。

接口与扩展位置

接口 用途
GET /agent/api/admin/plugins 获取支持的插件、是否已配置、来源、修改时间及加密服务就绪状态
POST /agent/api/admin/plugins/save 保存或清除指定供应商凭据；空输入保留
POST /agent/api/admin/plugins/test 测试已保存的凭据；不接受任意目标 URL

写请求须为来自当前平台的同源 JSON，大小不超过 16 KB。普通账号返回 403，未登录请求被会话认证拒绝。错误供应商、非法密钥和矛盾的保存 / 清除请求被拒绝。

保存参数为 provider、credential、clear。供应商 ID 当前为 tianyancha、amap；测试只提交 provider。读取接口不会返回明文或密文。

供应商目录和加密存储：backend/bizpkg/config/plugincredentials/；新增供应商时在目录中明确插件 ID、认证规则和固定测试接口，补充其成功 / 失败识别。管理页由目录自动生成，不开放任意地址携带平台密钥的测试能力。

执行接入：backend/domain/plugin/service/credential_overlay.go；日志脱敏：backend/domain/plugin/service/tool/credential_redaction.go；管理页资源：backend/conf/admin/plugin-credentials.js、.css；独立路由：backend/api/router/plugin_credentials.go。

发布与回退

发布前备份目录：/home/coze/backups/plugin-admin-20261111-233030，包含原 Compose、管理页及备份脚本。需要回退时恢复该目录中的 compose.json、index.html 和 backup.py，再重建 coze-server。首次发布前不存在的新增管理页资源可在核对后移除。
