使用入口与操作

打开智能体的“添加插件”窗口，点击左侧“搜索工具”，下方展示“全部”和有工具的分类。每个分类右侧显示工具数量，选中后右侧只展示对应工具；工具卡片同时显示分类标签。

在分类内输入关键词，可按工具名称或介绍搜索；切换分类保留关键词，列表回到第一页。搜索结果取“当前分类”和“关键词”的交集；清空关键词恢复当前分类全部工具，点击“全部”取消分类限制。分类数量表示整个目录的数量，不随当前关键词变化。分类按钮支持键盘焦点和回车选择。

“资源库-工具”“资源库-系统”以及可用时的“Coze.cn 插件”入口继续保留。新增分类仅作用于本平台的“搜索工具”目录，不将第三方插件加入系统资源库，也不更改原工具的授权要求。分类后仍可展开工具、添加到智能体或工作流。

分类加载失败时保留“全部”列表并显示重试入口。网络恢复后点击重试即可重新加载分类；没有匹配结果时显示原有空列表提示，不以其他分类的工具替代结果。

接口与实现位置

复用原有接口，没有新增数据库表或迁移：

GET /agent/api/marketplace/product/category/list?entity_type=2
GET /agent/api/marketplace/product/list?entity_type=2&sort_type=1&page_num=1&page_size=20&category_id=1005&keyword=飞书

分类接口返回稳定的 ID、中文名称、顺序和当前数量，仅列出已有工具的分类。列表接口先按类别及名称、介绍关键词筛选，再进行稳定排序和分页；total 为筛选后的匹配数量，has_more 表示是否还有下一页。不传分类或传 0 时查询全部；未知分类返回空列表。每页默认 20 条，上限 100 条。

历史目录可能来自无序配置集合，且部分工具没有商品 ID，因此分页前按商品 ID、工具 ID 做确定性排序，避免跨请求重复或漏项。不会写回配置、更换原工具 ID 或复制工具。

位置 作用
backend/domain/plugin/entity/market_category.go 稳定分类定义、原工具 ID 到分类的映射、未知工具回退

frontend/packages/agent-ide/plugin-shared/src/components/plugin-panel/index.tsx 工具卡片显示分类标签

后续增加工具与维护

继续按原流程新增和维护“搜索工具”中的插件，并在 marketPluginCategoryIDs 中配置插件 ID 对应的分类 ID；需要新类别时同时增加稳定分类定义和前端图标。不要复用已有分类 ID 表达另一种含义，否则收藏界面、已有筛选缓存等可能失去一致性。

尚未归类的新工具仍能在“全部”与“实用工具”中被找到。有资源时“实用工具”才出现。系统资源库独立发布的插件不经过此目录映射；无需为了展示系统联网插件而修改第三方工具清单。

修改映射或工具目录后先重新构建后端，并验证各分类数量相加等于“全部”的数量。前端会在打开插件窗口时请求分类列表；已有窗口可重新打开刷新。分类名称、数量与标签均来自后端，前端不另外维护一份归属表。

部署与回退

Go 构建目录为 /home/coze/build/source/backend，前端构建目录为 /home/coze/build/subpath-source。产物、缓存、发布目录与备份使用 /home/coze；部署前执行 /home/coze/ops/capacity.py --guard，根分区至少保留 15 GiB、/home 至少保留 25 GiB，并遵循原使用率守卫。

确认知识库队列与任务中心没有运行中作业，先执行 /home/coze/ops/backup.py 保存元数据库和插件凭据密钥的配对备份，再备份 Compose，更新 coze-server 镜像及 coze-web 静态目录。保留 /agent/ 路由、Nginx 配置、插件凭据密钥只读挂载、联网查询回环服务及双 Embedding 工作进程配置。

发布记录位于 /home/coze/build/plugin-categories/release.json，包括当前镜像、前端目录、SHA256 与本次 Compose 备份路径。回退时恢复该次备份的 Compose，再执行 /home/coze/ops/compose.sh up -d --no-deps coze-server coze-web。若需回退整个分类功能，使用首次分类部署前保存的 /home/coze/backups/plugin-categories-20261115-222249/compose.json。不使用旧数据库覆盖之后的用户数据，不修改厂商密钥。

验收与排查

专项记录见 搜索工具分类验收.json，服务及原知识数据核对见 搜索工具分类运行核对.json。使用临时普通账号和临时智能体完成页面选择与绑定，结束后清理；未登录或修改真实客户账号，未执行模型或厂商工具调用。

验证内容包含全部 18 个工具无遗漏、七个分类归属与数量、分类内搜索、大小写、无结果、分页总数与跨请求顺序、标签、键盘选择、加载失败重试、系统资源独立入口及筛选后绑定原工具。后端增加分类搜索分页、数量与回退、跨请求排序三项测试，保留原 SaaS 列表回归检查。前端完整构建成功；定向类型诊断与修改前基线比较未新增错误，原适配器依赖上下文中有 10 项历史未使用 @ts-expect-error 诊断，未借本次分类需求扩展处理。

2026-11-15 已部署并通过 24 项 API 与页面检查；另连续 8 轮、共 24 次分类分页请求，均保持相同顺序，未发现重复或遗漏。当前后端镜像为 coze-local/server:plugin-categories-e07e69038fef，前端目录为 /home/coze/releases/web-agent-categories-437665137d0d。MD 与 HTML 同步生成，桌面、手机布局及源文件摘要核对通过。

若看不到分类，先刷新页面或重新打开窗口，核对前端发布目录与分类接口；若数量不符，核对工具清单和归属映射；若搜索后结果为空，检查当前类别和关键词是否同时匹配。分类与厂商实际调用是不同阶段：授权报错应沿用原有插件授权排查，不通过改变分类或重新填写其他厂商密钥处理。
