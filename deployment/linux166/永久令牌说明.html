API 授权永久令牌使用与运维说明

部署配置、磁盘规划与日常维护操作。容量和验收状态为原文记录的历史快照。

打开平台 下载 Markdown

更新日期：2026-11-11。适用环境：ssh linux166，药销易-智能体平台。

使用方式

  1. 打开 https://ai.yaoxiaoyi.com/agent/ 并登录。
  2. 点击左下角头像，进入“API 授权”，点击“添加新令牌”。
  3. 填写名称，在“过期时间”中选择“永久有效”，点击“确定”。
  4. 保存创建成功页面展示的令牌。明文令牌仅在创建时展示。

原有“1 天”“30 天”和“自定义”选项继续保留。新建时需主动选择有效期。已有令牌不会自动改为永久；需要永久令牌时应新建，替换调用方凭据后删除旧令牌。编辑操作仍只修改名称。

外部调用继续使用 Authorization: Bearer <令牌>，例如调用地址 https://ai.yaoxiaoyi.com/agent/v3/chat。业务参数按原有智能体接口要求填写。

有效期与撤销规则

情况 调用行为
永久令牌 不因时间流逝到期
限时令牌 当前时间达到到期时间时拒绝调用
删除令牌 后续调用立即无法通过身份认证
停用账号 该账号包括永久令牌在内的所有令牌无法通过认证
重新启用账号 尚未撤销且未到期的令牌恢复调用资格
重置密码 清除网页会话；令牌仍按原有账号管理规则处理

永久仅表示没有到期时间，仍受账号状态及原有资源访问权限约束。

本次同时补齐后端到期检查。此前后端未在鉴权时检查到期时间，因此历史上已过期但仍在使用的限时令牌，本次发布后会被拒绝，需要重新创建有效令牌。

接口与存储约定

创建接口：POST /agent/api/permission_api/pat/create_personal_access_token_and_permission，需要当前用户网页登录会话。

{
  "name": "业务系统调用",
  "duration_day": "permanent"
}

永久令牌使用既有前端约定 expire_at = -1，存入 api_key.expired_at。已核实当前数据库列为有符号 bigint，无需建表、改字段或迁移历史数据。

自定义到期时间必须大于当前 Unix 秒数；负数天数、零天数、非法选项及会造成计算溢出的天数被拒绝。只有永久选项可以创建无到期时间的令牌。

构建、发布与回退

前端构建沿用 build-agent-web.sh。后端专项构建使用 build-token-server.sh，在独立构建副本中执行。构建缓存、临时目录、镜像及发布文件继续存放于 /home/coze，发布前执行容量门限检查和数据库元数据备份。

发布只替换 coze-server 镜像和 coze-web 的前端静态目录，保留现有数据库、模型配置与 /agent/ 路径适配。实际镜像、前端版本、备份目录及验收结果记录在 永久令牌验收.json。

原始运行 Compose 备份目录记录于 /home/coze/ops/permanent-token-backup-path。需要撤回本次发布时，在确认此后没有其他发布覆盖配置的前提下执行：

backup=$(cat /home/coze/ops/permanent-token-backup-path)
case "$backup" in /home/coze/backups/permanent-token-*) ;; *) exit 1;; esac
cp "$backup/compose.json" /home/coze/src/coze-studio/docker/docker-compose.deploy.json
/home/coze/ops/compose.sh up -d --no-deps coze-server coze-web
docker exec coze-web nginx -t
docker exec coze-web nginx -s reload

回退不会撤销已创建的令牌。如需停止某个令牌的调用，应明确删除对应令牌。数据库无需恢复。

验收范围

覆盖有效期解析、永久及限时鉴权、删除撤销、账号停用与恢复、原有期限选项、非法输入，以及正式 /agent/ 页面选择永久、创建和刷新后的显示。线上测试使用独立临时账号，结束后清理账号、个人空间及令牌；不改变真实账号密码，不记录明文令牌。
