# 药销易智能体平台登录页与品牌配置

更新日期：2026-11-10。服务器：`ssh linux166`。

## 展示内容

平台入口为 `https://ai.yaoxiaoyi.com/agent/`，登录页为 `https://ai.yaoxiaoyi.com/agent/sign`。

- 登录页左上角不再展示原 Coze 图形与“扣子”字样。
- 登录欢迎语为“药销易-智能体平台”。
- 登录页不再展示“开源协议”入口。
- 登录页中央标志、工作空间导航标志和管理后台品牌标志统一使用用户最新提供的药销易图片，并按原始比例展示。
- 登录页、工作空间和管理后台的标签页标题使用“药销易-智能体平台”。智能体、应用和工作流编辑页保留资源名称等上下文，品牌名称统一为“药销易-智能体平台”。
- 主平台与管理后台的 favicon 使用同一份 ICO 图片，提供 16、32、48、64、128、256 像素尺寸。

## 图标来源

原图为用户最新提供的 `药销易-竖-纯图-无字-128-128.png`，尺寸为 128×128，包含透明通道。源 PNG 原样复制，不改变图形和颜色，替代之前的咨微标志。

| 用途 | 文件 |
| --- | --- |
| PNG 原图及兼容图标 | `frontend/apps/coze-studio/assets/favicon.png` |
| 主平台 ICO | `frontend/apps/coze-studio/assets/favicon.ico` |
| 管理后台 ICO | `backend/conf/admin/favicon.ico` |
| 管理后台品牌标志 | `backend/conf/admin/platform-logo.png` |
| 登录页中央标志 | `frontend/packages/foundation/account-ui-adapter/src/pages/login-page/platform-logo.png` |
| 生成 ICO 的脚本 | `deployment/linux166/scripts/generate-brand-icons.py` |

ICO 使用透明正方形画布，在保持宽高比的前提下生成多个尺寸。管理后台 ICO 与主平台 ICO 的字节完全一致。生成脚本依赖 Pillow，仅用于开发时转换资源，前端运行和构建直接使用已生成文件。

## 关键配置

1. `frontend/packages/foundation/account-ui-adapter/src/pages/login-page/index.tsx` 移除左上品牌节点，并设置欢迎语。
2. 同目录 `favicon.tsx` 引用新的中央标志。
3. `frontend/apps/coze-studio/index.html` 和 `rsbuild.config.ts` 配置初始页面标题及 ICO 引用，并把图标复制到构建目录。
4. `frontend/packages/arch/i18n/src/brand.ts` 提供统一的 `platformDisplayName`。全局布局的两层组件库 `Layout` 显式传入该值，避免组件库自己的默认标题覆盖 HTML。
5. `frontend/packages/arch/resources/studio-i18n-resource/src/locales/zh-CN.json`、`en.json` 更新运行时平台名称、应用和工作流标题。页面标题工具、应用、工作流及发布页同步使用统一品牌名称。React Helmet 会在页面加载后设置标题，因此仅修改 HTML 的 title 不足以完成品牌更新。
6. `backend/conf/admin/index.html` 设置管理后台标题，并使用相对路径加载后台 ICO，兼容公网 `/agent/` 与内网入口。

主平台图标地址为 `/agent/favicon.ico?v=yaoxiaoyi-2`，管理后台使用自身目录下的 `favicon.ico?v=yaoxiaoyi-2`。版本参数用于更新浏览器图标缓存；以后替换图标时应同时递增版本参数。

## 构建、发布与回退

沿用[子路径访问说明](子路径访问说明.md)中的独立构建、版本目录挂载和回退流程。变更前端产物与后台静态文件，不修改模型凭据、账号密码和数据库结构。

构建命令：

```bash
bash /home/coze/ops/build-agent-web.sh /home/coze/build/subpath-source
```

部署前保留原 Compose、Nginx 配置和后台文件，发布完整的 `dist` 到新的 `/home/coze/releases/web-agent-版本` 目录，切换前端容器的只读挂载。当前版本、图标摘要和验证记录见 `品牌配置验收.json`。

浏览器若仍显示旧图标或旧标题，可先使用 Ctrl+F5 强制刷新。
