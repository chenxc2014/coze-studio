# 搜索工具分类使用与运维说明

更新日期：2026-11-15。平台入口：`https://ai.yaoxiaoyi.com/agent/`。

## 使用入口与操作

打开智能体的“添加插件”窗口，点击左侧“搜索工具”，下方展示“全部”和有工具的分类。每个分类右侧显示工具数量，选中后右侧只展示对应工具；工具卡片同时显示分类标签。

在分类内输入关键词，可按工具名称或介绍搜索；切换分类保留关键词，列表回到第一页。搜索结果取“当前分类”和“关键词”的交集；清空关键词恢复当前分类全部工具，点击“全部”取消分类限制。分类数量表示整个目录的数量，不随当前关键词变化。分类按钮支持键盘焦点和回车选择。

“资源库-工具”“资源库-系统”以及可用时的“Coze.cn 插件”入口继续保留。新增分类仅作用于本平台的“搜索工具”目录，不将第三方插件加入系统资源库，也不更改原工具的授权要求。分类后仍可展开工具、添加到智能体或工作流。

分类加载失败时保留“全部”列表并显示重试入口。网络恢复后点击重试即可重新加载分类；没有匹配结果时显示原有空列表提示，不以其他分类的工具替代结果。

## 接口与实现位置

复用原有接口，没有新增数据库表或迁移：

```text
GET /agent/api/marketplace/product/category/list?entity_type=2
GET /agent/api/marketplace/product/list?entity_type=2&sort_type=1&page_num=1&page_size=20&category_id=1005&keyword=飞书
```

分类接口返回稳定的 ID、中文名称、顺序和当前数量，仅列出已有工具的分类。列表接口先按类别及名称、介绍关键词筛选，再进行稳定排序和分页；`total` 为筛选后的匹配数量，`has_more` 表示是否还有下一页。不传分类或传 0 时查询全部；未知分类返回空列表。每页默认 20 条，上限 100 条。

历史目录可能来自无序配置集合，且部分工具没有商品 ID，因此分页前按商品 ID、工具 ID 做确定性排序，避免跨请求重复或漏项。不会写回配置、更换原工具 ID 或复制工具。

| 位置 | 作用 |
| --- | --- |
| `backend/domain/plugin/entity/market_category.go` | 稳定分类定义、原工具 ID 到分类的映射、未知工具回退 |
| `backend/application/plugin/market_categories.go` | 分类数量、关键词与类别交集、稳定排序与分页 |
| `backend/application/plugin/plugin.go` | 搜索工具列表与分类标签接入 |
| `backend/api/handler/coze/public_product_service.go` | 区分本地目录与原有 SaaS 分类请求 |
| `frontend/packages/agent-ide/plugin-modal-adapter/src/components/plugin-modal/plugin-filter/` | 分类导航、图标、数量、选中态及失败重试 |
| `frontend/packages/agent-ide/plugin-shared/src/service/fetch-plugin.ts` | 传递有效分类 ID，复用原有搜索、分页及缓存机制 |
| `frontend/packages/agent-ide/plugin-shared/src/components/plugin-panel/index.tsx` | 工具卡片显示分类标签 |

## 后续增加工具与维护

继续按原流程新增和维护“搜索工具”中的插件，并在 `marketPluginCategoryIDs` 中配置插件 ID 对应的分类 ID；需要新类别时同时增加稳定分类定义和前端图标。不要复用已有分类 ID 表达另一种含义，否则收藏界面、已有筛选缓存等可能失去一致性。

尚未归类的新工具仍能在“全部”与“实用工具”中被找到。有资源时“实用工具”才出现。系统资源库独立发布的插件不经过此目录映射；无需为了展示系统联网插件而修改第三方工具清单。

修改映射或工具目录后先重新构建后端，并验证各分类数量相加等于“全部”的数量。前端会在打开插件窗口时请求分类列表；已有窗口可重新打开刷新。分类名称、数量与标签均来自后端，前端不另外维护一份归属表。
